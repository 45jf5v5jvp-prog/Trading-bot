# Style guide — replace everything in this file with your own words

This file is the highest-leverage thing in the project. It is loaded into every
single conversation. The recorded answers in `qa/` teach the AI your phrasing; this
file teaches it your judgment.

Write it in first person, the way you'd explain yourself to a new junior advisor.
Don't polish it — talk. Dictate it if that's easier and paste the transcript in.
