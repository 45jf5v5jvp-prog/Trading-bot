# Robinhood Launch Bot

Automated Trading and Launch Bots for [Robinhood Chain](https://docs.robinhood.com/chain/),
trading permissionlessly-launched tokens on Uniswap V2. Same vault/keeper
architecture as the [PulseChain trading bot](https://github.com/45jf5v5jvp-prog/Trading-bot)
this was forked from - see `CLAUDE.md` for what's shared, what's changed, and
current status.

**Nothing here has been deployed or run yet.** See `CLAUDE.md` for the honest
current state and what's next.
